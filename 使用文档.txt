【系统简介】
面向中小型工厂（螺母等轻工业品）的每日台账管理系统：上传生产日报 / 出货
明细 / 退货记录 / 盘点表等文档 → 自动解析提取规格条目 → 匹配产品档案
→ 生成台账、看板与报表。技术栈 FastAPI + SQLite + Vue3，端口 8000。

【访问与账号】
  本机地址：http://127.0.0.1:8000
  云端地址：http://服务器公网IP:8000
  管理员：  admin / admin123   （首次登录会强制改密，改后即失效）
  员工账号：由管理员在「用户管理」中创建，密码由管理员设定并告知本人
  角色三级：admin（全部）/ manager（业务）/ employee（上传+看自己单据）

──────────────────────────────────────────────────
方式一：本机 Windows 启动（双击即用）
──────────────────────────────────────────────────
■ 首次安装（只做一次，需联网）
  1. 前提：已装 Python 3.11+ 和 Node.js 18+（均勾选"加入 PATH"）
  2. 双击 install.bat
     —— 自动完成：找 Python → 装后端依赖 → 装前端依赖 → 构建前端
  3. 看到 "Install done" 即成功

■ 日常启动
  双击 start.bat
  —— 自动完成：挑选装有依赖的 Python → 启动后端 → 4 秒后打开浏览器
  —— 会弹出一个黑色后端窗口，这个窗口不能关（关了服务就停了）

■ 停止系统
  直接关闭那个黑色后端窗口即可（数据已实时落盘 backend/data/，放心关）

■ 说明
  · 数据保存在 backend/data/（数据库 + 上传的文件），删这个目录 = 清空
    全部数据，请勿删除；换机迁移整个项目文件夹即可
  · start.bat 会自动跳过沙箱 Python（无依赖的解释器），只选能运行本
    项目的那个；若报 "No Python with project dependencies"，先跑
    install.bat

──────────────────────────────────────────────────
方式二：云端 Docker 部署（服务器推荐）
──────────────────────────────────────────────────
■ 前提
  服务器（如腾讯云 Lighthouse 2核2G 即可）已安装 Docker 和 docker
  compose 插件；安全组/防火墙放行 8000 端口

■ 步骤
  1. 把整个项目文件夹上传到服务器（git clone 或 scp 压缩包后解压）
  2. 进入项目目录，执行：
       docker compose up -d --build
     —— 首次构建约 3~8 分钟（自动构建前端 + 装后端依赖，含 OCR 库）
  3. 浏览器访问 http://服务器公网IP:8000

■ 常用命令
  查看日志：  docker compose logs -f
  停止：      docker compose down
  重启：      docker compose restart
  更新版本：  重新上传代码后 docker compose up -d --build
  （容器名 paper2ledger，开机自启 restart: unless-stopped）

■ 数据与备份
  · 数据通过卷挂载保存在宿主机 ./backend/data/，容器重建不丢数据
  · 备份 = 复制整个 backend/data/ 目录；也可用系统内"数据备份"功能
    （登录后左侧菜单 → 数据备份 → 创建/下载 zip）

■ 可选：大模型配置（AI 提取 / AI 助手 / AI 周报）
  · 方式 A：登录系统 → 系统设置 → 填 LLM API 地址 / Key / 模型名
  · 方式 B：docker-compose.yml 的 environment 段填 LLM_* 三项后重建
  · 不配置也能用：文档走模板/规则提取，仅 AI 相关功能不可用

──────────────────────────────────────────────────
方式三：云端 Linux 裸机部署（无 Docker 时备选）
──────────────────────────────────────────────────
  1. 前提：Python 3.11+、Node.js 18+（Ubuntu: apt install python3 nodejs npm）
  2. 首次：进入项目目录执行  ./install.sh
  3. 启动：./start.sh   （后台常驻，日志在 backend/run.log）
  4. 停止：pkill -f 'uvicorn app.main'
  说明：与方式二等价，只是依赖装在宿主机；换机/重装系统需重跑 install.sh

──────────────────────────────────────────────────
常见问题
──────────────────────────────────────────────────
Q1 双击 start.bat 后浏览器打不开页面？
   · 看黑色窗口报什么错：
     - "No Python with project dependencies" → 先跑 install.bat
     - "address already in use / 端口被占用" → 之前的后端没关干净，
       关掉旧黑窗口再启动；或任务管理器结束 python 进程
     - 窗口闪退 → 在 cmd 里手动运行看完整报错
   · 等待 5~10 秒再刷新，首次启动要加载 OCR 模型，稍慢

Q2 云端访问不了？
   · 依次检查：服务起来没（docker ps）/ 安全组放行 8000 没有 /
     服务器内 curl http://127.0.0.1:8000/api/health 返回 ok 没有

Q3 上传图片提取不出内容？
   · 图片走 OCR 识别，首次使用需加载模型（约 10~30 秒）属正常；
     模糊、倾斜的小票识别率会下降，建议拍照清晰端正

Q4 冒烟测试（开发者用）注意事项
   · cd tests && python smoke_test.py（需后端已在 8000 运行）
   · 测试会清空系统设置里的 LLM 配置！跑之前备份、跑完恢复：
       python _llm_backup.py backup    （跑测试前）
       python _llm_backup.py restore   （跑测试后）
   · 共 98 项断言，可重复运行
